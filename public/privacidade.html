Política de Privacidade do AthesChat

Última atualização: Novembro de 2026

1. Quais dados nós coletamos?

O AthesChat preza pelo anonimato. Não pedimos e-mail, senha ou nome para você usar o chat. No entanto, para garantir a segurança, coletamos:

  • Endereço IP: Coletado automaticamente para possibilitar banimentos (em caso de violação dos Termos de Uso).
  • Localização Aproximada: Estimada via API (baseada no IP) para mostrar o Estado (ex: SP, RJ) ao seu parceiro de conversa. Você pode desativar isso nas Configurações.
  • Mensagens: As mensagens não são salvas permanentemente. Elas são transmitidas em tempo real (via WebSockets) e desaparecem quando a conversa termina.

2. Como usamos seus dados?

Usamos o IP para proteção contra bots, spam e para aplicar banimentos. As denúncias (com o texto da mensagem e o IP) ficam salvas temporariamente para nossa equipe de moderação avaliar e tomar providências.

3. Armazenamento no Dispositivo (Cookies e LocalStorage)

Salvamos dados no seu navegador para melhorar sua experiência. Isso inclui:

  • Preferências de visualização (cor das mensagens, tamanho da fonte).
  • Volume dos sons e configurações.
  • O seu consentimento de que já aceitou os termos.
  • Anúncios futuros (Google AdSense) poderão usar cookies para personalização.

4. Compartilhamento de Dados

Nós não vendemos nem alugamos seus dados. Utilizamos serviços de terceiros (como a API ipapi.co para pegar a localização e a hospedagem Render para rodar o código) que possuem suas próprias políticas de segurança.

5. Seus Direitos (LGPD)

Como os dados são anônimos e temporários, não conseguimos identificar quem é você. No entanto, se você tiver dúvidas sobre seus dados ou quiser solicitar a remoção de algum registro (como uma denúncia ou banimento), entre em contato pelo e-mail: suporte@atheschat.com.br.

6. Segurança

Implementamos medidas como filtros de palavras, limite de mensagens (anti-spam) e servidores seguros. Contudo, lembramos que nenhum sistema é 100% invulnerável.
