Política de Privacidade do AthesChat

Última atualização: Novembro de 2026

1. Quais dados nós coletamos?

O AthesChat preza pelo anonimato. Não pedimos e-mail, senha ou nome para você usar o chat. No entanto, para garantir a segurança e o funcionamento, coletamos:

  • Endereço IP: Coletado automaticamente para possibilitar banimentos (em caso de violação dos Termos de Uso) e limitar spam. Não é exibido a outros usuários.
  • Localização Aproximada: Estimada via API externa (ipapi.co) a partir do IP, para mostrar apenas o Estado (ex: SP, RJ) ao seu parceiro de conversa. Você pode desativar isso nas Configurações do chat.
  • Mensagens: As mensagens não são salvas permanentemente. Elas são transmitidas em tempo real (via WebSockets) e desaparecem quando a conversa termina. A única exceção são mensagens anexadas a uma denúncia feita por outro usuário.
  • Denúncias: Quando um usuário denuncia outro, armazenamos o IP do denunciado, o motivo, o texto da mensagem (se anexado) e a data. Esses dados ficam retidos por até 90 dias para análise da moderação e depois são removidos.
  • Estatísticas agregadas: Contamos mensagens totais e usuários online de forma anônima e agregada. Não é possível identificar usuários individuais a partir dessas estatísticas.

2. Como usamos seus dados?

Usamos o IP para proteção contra bots, spam, abuso e para aplicar banimentos. As denúncias ficam salvas temporariamente para nossa equipe de moderação avaliar e tomar providências. Não usamos seus dados para publicidade comportamental.

3. Armazenamento no Dispositivo (Cookies e LocalStorage)

Salvamos dados no seu navegador via localStorage para melhorar sua experiência. Isso inclui:

  • Preferências de visualização (cor das mensagens, tamanho da fonte, fundo).
  • Volume dos sons e configurações de silêncio.
  • O seu consentimento de que já aceitou os termos (chave atheschat_terms_accepted).
  • Token de sessão do painel administrativo (apenas para moderadores).

Não usamos cookies de rastreamento de terceiros. Anúncios futuros (ex: Google AdSense), se implementados, poderão usar cookies próprios — você será notificado quando isso ocorrer.

4. Compartilhamento de Dados

Nós não vendemos nem alugamos seus dados. Utilizamos serviços de terceiros que possuem suas próprias políticas de segurança:

  • ipapi.co — para estimar localização a partir do IP.
  • Provedor de hospedagem (ex: Render, Railway, VPS) — para executar o servidor.
  • CDN do Socket.io — para carregar a biblioteca de tempo real no navegador.

5. Seus Direitos (LGPD — Lei 13.709/2018)

Como os dados são anônimos e temporários, não conseguimos identificar quem é você individualmente. No entanto, se você tiver dúvidas sobre seus dados ou quiser solicitar a remoção de algum registro (como uma denúncia ou banimento vinculado a um IP específico), entre em contato pelo e-mail: suporte@atheschat.com.br.

Você tem direito a:

  • Confirmação da existência de tratamento de dados.
  • Acesso aos dados (quando identificáveis).
  • Correção de dados incompletos ou desatualizados.
  • Eliminação de dados tratados com consentimento.
  • Informação sobre compartilhamento com terceiros.

6. Retenção de Dados

  • Mensagens: não armazenadas (exceto em denúncias).
  • Denúncias: até 90 dias.
  • Banimentos: permanentes ou até a expiração definida pelo moderador.
  • Logs administrativos: últimas 200 ações, mantidos para auditoria.
  • Estatísticas agregadas: mantidas indefinidamente (sem dados pessoais).

7. Segurança

Implementamos medidas como filtros de palavras, limite de mensagens (anti-spam), tokens JWT assinados para o painel administrativo e servidores seguros. Contudo, lembramos que nenhum sistema é 100% invulnerável.

8. Menores de Idade

O AthesChat é destinado exclusivamente a maiores de 18 anos. Não coletamos intencionalmente dados de menores. Se identificarmos uso por menor, a conta e o IP serão banidos.

9. Alterações nesta Política

Esta política pode ser atualizada a qualquer momento. A data de "Última atualização" no topo indica a versão vigente. Alterações significativas serão comunicadas via letreiro no chat.

10. Contato

Para exercer seus direitos ou tirar dúvidas: suporte@atheschat.com.br.
